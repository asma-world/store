# متجر عالم اسما (Asma World) - E-Commerce Web Application

متجر إلكتروني حديث وسريع وفائق الجمال مخصص للأجهزة المنزلية والكهربائية لعلامة **"عالم اسما" (Asma World)**، مطور بالكامل باستخدام **Vanilla HTML5, CSS3, JavaScript (ES6+)** دون أي أطر عمل خارجية (No React, No Tailwind).

## 🚀 المميزات الرئيسية (Core Features)

### 1. شريط التنقل ومحرك البحث اللحظي (Header & Live Search)
- شريط إعلانات علوي يضم أحدث العروض ورابط القناة الرسمية على يوتيوب.
- شعار تفاعلي راقٍ للأجهزة المنزلية.
- محرك بحث فوري (Live Real-Time Search) يبحث في أسماء الأجهزة ومواصفاتها بشكل لحظي.
- زر مباشر لقناة اليوتيوب `@asma_world` بنقطة نابضة حمراء حية.
- سلة مشتريات ديناميكية تعرض عداد القطع وقيمة الدفع الفوري المطلوب.
- شريط تصنيفات وأقسام ديناميكي مزود بـ **أسهم تمرير يمين ويسار تفاعلية** لسهولة استعراض كافة الفلاتر والتصنيفات بسلاسة على كافة الأجهزة، مع عدادات حية لكل قسم.

### 2. القسم الترويجي (Hero Banner & Brand Showcase)
- واجهة ترويجية غنية (Hero Banner) بألوان العلامة وشارات الثقة والضمان المعتمد ونظام الدفع (20% عربون والباقي عند الاستلام).
- زر مباشر للاشتراك في قناة اليوتيوب الرسمية `@asma_world`.

### 3. كتالوج المنتجات وفلاتر متطورة (Product Catalog & Live Filters)
- كتالوج جاهز ونظيف للبدء بإضافة أجهزتك ومنتجاتك من الصفر عبر لوحة الإدارة.
- كروت منتجات تفاعلية مع تأثيرات تكبير، زر معاينة سريعة عريض ومخصص (Quick View) أسفل زر الشراء، ومشغل فيديو يوتيوب اختياري لكل جهاز.
- **الحسبة المالية لكل جهاز**: السعر الإجمالي، قيمة العربون المخصص لكل جهاز، والمبلغ المتبقي كاش عند الاستلام.
- **حالة توفر المخزون**: شارة "غير متوفر حالياً" وتعطيل الشراء تلقائياً عند إيقاف توفر المنتج.
- فلترة متقدمة حسب التصنيف، السعر (Slider)، البحث، وترتيب المنتجات.

### 4. سلة المشتريات وخيارات الدفع (Interactive Cart Drawer & Payment Options)
- درج جانبي ناعم (Slide-out Cart Drawer) مع خلفية معتمة بضبابية زجاجية.
- إمكانية زيادة ونقصان الكميات وحذف العناصر فورياً.
- **محدد خيارات الدفع**:
  - دفع العربون فقط بالبطاقة والباقي كاش عند الاستلام.
  - دفع إجمالي المبلغ كاملاً 100% بالبطاقة البنكية.
- حسابات مالية مفصلة تتغير لحظياً حسب خيار الدفع المحدد.

### 5. نظام إتمام الطلب والدفع الإلكتروني التجريبي (Checkout & Mock Card Payment)
- نموذج متكامل لبيانات العميل وعنوان الشحن في جميع محافظات مصر.
- بطاقة دفع إلكتروني تفاعلية تحاكي الفيزا والماستركارد مع كشف نوع البطاقة وتنسيق الأرقام ومحاكاة المعالجة الآمنة (256-bit SSL).
- **فاتورة إلكترونية معتمدة وإيصال دفع فوري**:
  - رقم طلب فريد (`ASM-XXXXXX`) وتاريخ دقيق.
  - جدول تفصيلي بالأجهزة والكميات والأسعار.
  - إثبات سداد الدفع الإلكتروني والمبلغ المتبقي كاش (أو 0 في حالة السداد الكامل).
  - زر طباعة مباشر بتنسيقات طباعة نظيفة (`window.print()`).
  - زر تواصل ومتابعة فوري عبر الواتساب إلى الرقم `01032997502`.

### 6. قسم المقر الرئيسي والتواصل المباشر (Store Headquarters & Direct Contact)
- بطاقات تفاعلية أنيقة لمقر المتجر الرسمي في **محافظة القليوبية - مركز شبين القناطر - كفر طحا**.
- أزرار اتصال مباشر ورابط واتساب فوري مع رقم المبيعات `01032997502`.
- مواعيد العمل وتفاصيل الشحن والفحص والمعاينة قبل السداد.

### 7. لوحة إدارة المتجر الشاملة (Admin Management Panel)
- **طلبات العملاء**: استعراض كافة الطلبات، البحث فيها، تحديث حالتها، وعرض فواتيرها.
- **إدارة وتعديل الأجهزة**: جدول تحكم كامل لتعديل الأجهزة، مسحها، واستبدال الصور من الجهاز، وتبديل حالة التوفر (متوفر / غير متوفر).
- **إضافة جهاز جديد مع رفع الصور من الجهاز**: نموذج متكامل يدعم رفع صور الأجهزة مباشرة من الكمبيوتر أو الهاتف بالسحب والإفلات مع ضغط ومعاينة فورية (أو عبر رابط URL)، وتحديد قيمة العربون المطلوب وحالة التوفر فوراً.
- **إدارة وترتيب الفلاتر والأقسام**: إضافة أقسام جديدة، تعديل أسمائها وأيقوناتها، مسحها، وتغيير **ترتيب ظهورها (تقديم للأعلى ⬆️ / تأخير للأسفل ⬇️)** فورياً مع الحفظ التلقائي.
- **لوحة المؤشرات**: إجمالي المبيعات، المحصل بالفيزا، المتبقي كاش، وإجمالي الطلبات.

## 💻 طريقة التشغيل (How to Run)

يمكنك تشغيل المتجر بسهولة عبر فتح ملف `index.html` مباشرة في أي متصفح حديث (Chrome, Edge, Firefox, Safari) أو عبر تشغيل خادم محلي مثل `Live Server` أو خادم بايثون:

```bash
# باستخدام Python
python -m http.server 8000
```
ثم فتح المتصفح على الرابط: `http://localhost:8000`
